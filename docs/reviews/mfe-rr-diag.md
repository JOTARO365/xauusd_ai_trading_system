# Intraday fade — MFE + SL×TP grid (จุด) (2026-08-13)

2 algo fade (intraday, ปิดสิ้นวัน UTC): SL+TP ควร fix กี่จุด? (SL/TP ห่างเกิน = เทรดไม่จบในวัน + ราคากลับมาโดนหน้าทุน)

- **MFE med/p75** = ระยะ (จุด) ที่ราคาไปถูกทาง **สูงสุด**ในวัน (median / 75th pct) — pure excursion ไม่มี SL. บอก TP ที่ realistic.
- **MAE med/p75** = ระยะ (จุด) ที่ราคาไปผิดทางสูงสุด — บอก SL floor (SL แคบกว่านี้ = โดนตัดก่อนเด้ง).
- **best SL/TP** = คู่ (จุด) ที่ expectancy (จุด/ไม้) สูงสุด จาก grid. หัก spread แล้ว. intraday (ปิดสิ้นวัน).
